# SendSong — sito prodotto

Sito statico (HTML, CSS, JS) per SendSong, pubblicato da [nikuniku74/sendsong-site](https://github.com/nikuniku74/sendsong-site) su GitHub Pages: [nikuniku74.github.io/sendsong-site/](https://nikuniku74.github.io/sendsong-site/).

Nessuna build: apri i file in locale o pubblica la cartella `website/` (o la root del repo Pages).

- **Lingue:** IT / EN (`localStorage` chiave `sendsong-lang`, toggle in header)
- **Tema:** scuro di default, chiaro con `prefers-color-scheme: light` o `?theme=light|dark`
- **Asset brand:** `assets/img/mark.png` (+ `mark-64/128/256.png`, trasparenti, rigenerati da `python3 store/make_mark.py`), `icon.png`, `icon-180.png`
- **Screenshot:** `assets/img/screens/<nome>.{it,en}.png`
